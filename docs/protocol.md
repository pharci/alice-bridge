# Транспорт и маршрутизация

```text
Штатное ASR колонки
  → ADB forward → Quasar IPC → маршрутизация
  → GET /v1/requests → агент
  ← POST /v1/responses ← ответ агента
  → maind --cli → «повтори за мной …» → штатная речь
```

Модель и агент живут вне ядра. Ядро не вызывает Ollama, не хранит ключи провайдера
и не ведёт историю модели. `up` только запускает отдельный модуль рядом с ядром.

## Проверенный IPC Мини 2

TCP на колонке: `127.0.0.1:9875`, на ПК — ADB forward на порт `bridge.ipc_port`.
Кадр: длина uint32 little-endian, затем protobuf до 4 МиБ.

| Поля | Содержимое |
|---|---|
| QuasarMessage 253 / 252 | Тип / тело |
| Тип 3, AliceState 7 | ID исходного голосового запроса |
| AliceState 15 → 1 / 2 | Распознанный текст / признак финального результата |
| AliceState 3 → 5 | JSON штатного ответа |
| AliceState 14 → 1 | Текст речевого ответа; не подтверждение звука |

При подключении первое кэшированное состояние не воспроизводится.
Повторы финального ASR дедуплицируются по ID.

В `auto` ядро проверяет `response.directives` штатного JSON:
речевые директивы отправляются агенту, остальные сохраняются за Алисой.
Сценарии могут создавать дочерний `header.request_id`: связь с голосовым ID
из AliceState учитывается, такой запрос сохраняется штатному движку.
Физические действия не отменяются и не запускаются заново.

Для речи используется отдельный процесс `maind --cli` через ADB. Команды и текст
передаются отдельными строками; переносы из ответа очищаются. Логи устройства,
которые могут содержать идентификаторы, не сохраняются этим клиентом.

## Ограничения

- Внутренний протокол конкретной прошивки, без гарантии совместимости обновлений.
- ASR и TTS зависят от облака Яндекса; локальная модель не делает колонку офлайн.
- Сценарий только с речью и без отдельного ID может уйти агенту.
- Начало штатной реплики иногда успевает прозвучать до отмены.
- Один поток диалога; новая реплика отменяет старую генерацию на уровне доставки.
  Уже запущенный запрос провайдеру ядро остановить не может.
- Вопрос выдаётся агенту один раз. Поздние ответы отклоняются, повторная отправка
  уже принятого ответа не воспроизводит его снова.
- При запуске нет тестового голоса, автосмены громкости или изменения файлов колонки.
