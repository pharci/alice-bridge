# Подготовка колонки

Мосту нужен только root ADB на порту 5555. Python, Ollama и дополнительные пакеты
на колонку не устанавливаются. Установка моста не меняет прошивку и настройки роутера.

## Если root ещё нет

Полные инструкции проекта, по которому получен доступ на тестовой Мини 2:
[получение root](https://github.com/Marker284/yandex-station-extended/blob/main/docs/start/root.md),
[закрепление доступа и SSH](https://github.com/Marker284/yandex-station-extended/blob/main/docs/start/ssh.md).

Порядок действий:

1. Проверьте модель и прошивку по инструкции получения root. Сам мост проверен на Мини 2.
2. Сбросьте колонку согласно инструкции своей модели. Сброс очищает `/data`, включая
   пользовательские изменения; для уже рутованной колонки этот шаг пропустите.
3. Начните привязку в «Доме с Алисой». Дойдите до выбора Wi-Fi и ввода пароля.
4. На этом экране остановитесь. Включите на роутере DNS из инструкции получения root.
   Его адрес и доступность проверяйте в исходной инструкции, не в настройках этого моста.
5. Нажмите подключение в приложении. Найдите IP колонки в списке клиентов роутера.
6. Подключитесь по ADB, закрепите доступ по инструкции проекта и верните обычный DNS.
   Настройка DNS нужна для получения root; для работы моста она не нужна.

```powershell
adb connect 192.0.2.10:5555
adb -s 192.0.2.10:5555 shell id
```

Замените условный адрес на IP колонки. Результат должен содержать `uid=0(root)`.

Практические поправки к сторонней инструкции:

- Если Dropbear вместо запуска печатает справку, проверьте его флаги. В использованной
  сборке `-E` не поддерживался: его пришлось убрать из команды запуска.
- Если SSH требует пароль, задайте его через `passwd` в root ADB, затем входите с ним.
  Приглашение пароля не означает, что у root уже известный пароль.
- Установка Entware/пакетов для этого моста не требуется.

## Если ADB пропал

Войдите своим SSH (если он установлен):

```powershell
ssh -p 2222 root@192.0.2.10
```

В оболочке колонки:

```sh
sh /system/vendor/quasar/activate_adb.sh --quasmodrom --network activate
netstat -lnt | grep 5555
```

Затем на ПК повторите `adb connect`. Команда `activate_adb.sh check` без флагов
не заменяет включение сетевого ADB и на проверенной прошивке могла его остановить.
Если IP изменился после перезагрузки, обновите `bridge.serial` в личном конфиге.

В обычной домашней сети ADB нужен только между ПК и колонкой; проброс портов
роутера для него и SSH не нужен.
